# whoami — Developer Portfolio

Personal portfolio of **Pratik  Late**, Full-Stack & Cloud Engineer.  
Built with a terminal-inspired dark aesthetic using Next.js 15 and Tailwind CSS v4.



---

## Sections

| Section | Description |
|---|---|
| **Hero** | Terminal-style intro with CTA buttons and social links |
| **About** | Background summary with Backend, Real-Time, and Cloud highlights |
| **Skills** | Categorized tech grid — Languages, Frameworks, Databases, Cloud |
| **Projects** | StudySync Microservices, Realtime Collaborator, Web Archiver & Crawler |
| **Contact** | Contact form with client-side state handling |

---

## Tech Stack

- **Framework** — Next.js 15 (App Router, React 19)
- **Language** — TypeScript (strict mode)
- **Styling** — Tailwind CSS v4
- **Animations** — Framer Motion
- **Icons** — Lucide React
- **Fonts** — Inter (UI) + JetBrains Mono (terminal accents)

---

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Deployment

The easiest way to deploy is via [Vercel](https://vercel.com):

```bash
npm run build
```

Push to GitHub and import the repo on Vercel — zero config needed for Next.js.
